Rules

Use rules to identify interesting WiFi sources and trigger automations.

To use a rule in Home Assistant, create an automation with trigger type Event and event type wifi_presence_scanner_rule_matched.

  • Name: Friendly label shown in events and UI.
  • SSID Regex: Pattern for SSID names, e.g. ^(DHL|UPS).
  • BSSID Prefix CSV: Comma-separated vendor prefixes, e.g. AA:BB:CC,11:22:33.
  • Min RSSI: Ignore weak detections below this signal level.
  • Cooldown: Seconds to suppress repeated rule-match events.

Useful event types for automations:

  • wifi_presence_scanner_rule_matched (recommended for your rules)
  • wifi_presence_scanner_wifi_discovered
  • wifi_presence_scanner_wifi_disappeared

Examples:

  • DHL van nearby: regex ^DHL, min RSSI -80, cooldown 120.
  • Courier vendor prefix: BSSID prefix AA:BB:CC, cooldown 90.
  • Street hotspot: regex mobile|hotspot, min RSSI -70.

Tip: start strict, then relax regex or prefix filters if you miss detections.
